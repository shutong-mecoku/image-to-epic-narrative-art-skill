# Image to Epic Narrative Art Skill

把用户上传的照片、电影截图、人物、群像、街景或物件，重构为具有不可能透视、极端尺度、主动负空间和图形化语言的原创“空间寓言”插画。默认只生成画面；只有用户明确提出时才启用叙事增强并附写短故事。

## 安装

将本仓库作为 Skill 导入支持 GitHub Skills 的客户端。仓库根目录的 `SKILL.md` 是入口文件。

## 调用示例

纯视觉：

> 使用 `$image-to-epic-narrative-art` 处理我上传的图片。默认纯视觉，不写故事。

叙事增强：

> 使用 `$image-to-epic-narrative-art` 处理我上传的图片，启用叙事增强，并在成图后写一段克制的虚构短故事。

Skill 需要客户端具备读取上传图片与图像生成/编辑的能力。它会依据源图选择零至两张内置参考，不会把全部参考混合使用。

## 设计原则

- 这不是滤镜，而是围绕源图关系重新组织空间。
- 透视、尺度和负空间是可选工具，不是每张图都必须套用的模板。
- 人物图优先保留姿势、身份和身体节奏；风景与建筑可做更强的空间重构。
- 默认不在画面中添加文字、标题、字幕或水印。
