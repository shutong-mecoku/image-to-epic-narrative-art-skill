# Composition Engine

目标是从源图片中发现一个可被放大的关系，再把它变成清楚、原创、可读的视觉寓言。

## Step 1: Lock factual anchors

先列出不能丢失的事实：

- 主体是谁或是什么；
- 关键动作与姿势；
- 必须保留的物件；
- 前后、左右、朝向、距离等空间关系；
- 能证明“仍是这张图”的独特轮廓、光线、服装或环境。

把故事性重构建立在这些锚点上。不要为了风格把主角、动作或场景全部换掉。

## Step 2: Find the narrative pressure

用一句话回答：

> 画面里的主体表面上正在做什么，实际上正被什么更大的力量推动、困住、吸引、追赶、改变或见证？

没有用户故事时，只从视觉证据推导情绪，不虚构确定身份。普通街景也可以是“被时间拉长的归途”，但不要擅自指定为战争、死亡或爱情背叛。

## Step 3: Choose one carrier already present

从源图内已有元素寻找主隐喻载体：

- 道路、走廊、楼梯、影子：命运、距离、不可逆前进；
- 绳索、发丝、布料、烟、光线：控制、记忆、歌声、时间；
- 水面、涟漪、云、雾：吞噬、循环、意识或遗忘；
- 门、窗、墙、桥：选择、边界、进入与离开；
- 手、脸、身体、建筑：可放大为地形、山体、牢笼或祭坛；
- 圆桌、车轮、杯子、钟、镜子：仪式、审判、循环或真相。

若主隐喻必须依赖一个源图中不存在的物件，先判断用户故事是否明确授权。否则改用源图已有元素。

## Step 4: Select one composition archetype

- **巨物／微人**：主体或压力成为巨大地形，微型人物标示尺度。适合压迫、敬畏、孤独、无法战胜的力量。
- **道路／刀刃／洪流**：一条几何路径贯穿画面并承担命运含义。适合进入、逃离、侵入、等待、决定。
- **圆环／祭坛／靶心**：事件围绕空心或裂缝组织。适合审判、循环、真相揭晓、群体仪式。
- **虚空／门槛**：大面积空白或深色域包围少量人物。适合死亡、记忆、离别、等待、未知。
- **负形／流线**：脸、声波、风、水或光以负形和线束出现。适合歌声、沟通、诱惑、情绪与无形力量。
- **连续变形／螺旋**：同一主体沿路径逐步改变。适合成长、腐化、循环、身份变化、时间经过。
- **局部身体景观化**：脸、手、躯干或衣褶成为整个空间。适合人物关系、凝视、巨大权力或内心冲突。

只选一种作为骨架。第二种只能作为很弱的呼应，不能争夺视觉中心。

## Step 5: Build the prompt with clear roles

生成指令应包含以下语义分区，可用自然语言而非固定标题：

1. **SOURCE IMAGE — factual source only**：说明需要锁定的人、物、动作、视点和辨识特征。
2. **STORY — narrative source**：若有故事，提炼冲突、不可逆瞬间与情绪；不要复制成长篇剧情简介。
3. **COMPOSITION TRANSFORMATION**：说明主隐喻、尺度关系、视角、负空间和方向轴。
4. **VISUAL LANGUAGE**：说明大色块、人物简化、线条、色彩和哑光版画质感。
5. **PRESERVE**：再次列出最容易跑偏的三至五个事实锚点。
6. **AVOID**：写实剧照、普通滤镜、3D 游戏感、无关神话元素、构图照搬、杂乱细节、文字与水印。

## Step 6: Control information density

- 第一眼：能读出一个大形体和方向关系。
- 第二眼：能找到主体与关键动作。
- 第三眼：才发现微型人物、纹样、裂缝或局部暗示。

如果所有元素都同样清楚、同样精细，说明层级失败。删减比继续添加更有效。

## Source-specific cautions

- **人物照**：保留面部结构、发型、姿势和服装标识；可把影子、头发、目光或衣褶变成空间。
- **街景／建筑**：保留可辨识轮廓和透视节点；可把道路、窗格、人流或灯光变成主轴。
- **风景**：不要默认加入神祇或巨人；优先让地形、天气、水流与微小主体产生尺度关系。
- **电影截图／艺术作品**：重构为独立视觉概念，不复制原作者的完整构图，也不把参考母样的具体元素搬入。
- **日常物件**：可放大为纪念碑、轨道、入口或祭坛，但仍需保留其形状与用途线索。
