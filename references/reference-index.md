# Reference Image Index

九张图片是视觉母样，不是可以复制的构图模板。每次先根据源图与故事选择**一张主参考**；若确有必要，再选一张只负责色彩或材质的辅参考。不得把九张同时交给生成模型，也不得复制其中的古希腊人物、器物或情节。

## 01 — Judgment Arrow

Path: `references/images/01-judgment-arrow.jpg`

- 核心：巨大的圆环仪式空间、微型围观者、武器成为贯穿画面的轴线。
- 适用：真相揭晓、审判、对峙、决断、公开身份、群体压力。
- 只学习：圆形空间与斜向锐线的冲突，红黑象牙白与旧金的层级。
- 不复制：弓箭、斧孔、宴席、兜帽人物。

## 02 — Fate Road

Path: `references/images/02-fate-road.jpg`

- 核心：道路既是人流，也是切入建筑的黑色命运；前景静止人物与远方流动群体对照。
- 适用：进入、侵入、归途、等待、城市命运、个人与群体。
- 只学习：巨构城市、黑色几何路径、尺度递进、少量金色微光。
- 不复制：城池、盔甲、剑和军队。

## 03 — Extreme Procession

Path: `references/images/03-extreme-procession.jpg`

- 核心：极端后方透视，巨大主体占满画面，绳索与人群形成放射性节奏。
- 适用：搬运、追随、共同推动、集体劳动、难以控制的庞大事物。
- 只学习：强制透视、微型人物、几何色面、清晰而克制的线束。
- 不复制：木马、城门、拉绳人群。

## 04 — Monumental Face

Path: `references/images/04-monumental-face.jpg`

- 核心：脸部成为地形，微型人物沿面部推进，单一焦点形成巨大威胁。
- 适用：凝视、恐惧、权力、肖像内心、人与无法撼动的对象。
- 只学习：局部裁切、脸部景观化、极端比例和唯一锐线。
- 不复制：独眼、长矛、古代士兵。

## 05 — Living Whirlpool

Path: `references/images/05-living-whirlpool.jpg`

- 核心：环境像器官般具有生命，圆形吸力与上方伸入的长形威胁夹击微小主体。
- 适用：困境、成瘾、混乱、追逐、自然危险、心理漩涡。
- 只学习：非对称俯视、活体环境、旋转线与单点强调色。
- 不复制：长船、兽首、红帆、海怪。

## 06 — Body as Landscape

Path: `references/images/06-body-as-landscape.jpg`

- 核心：身体局部与山体不可区分，巨大的黑色形体压入单一橙色色域。
- 适用：碾压、权力、狭窄通道、群体被更大力量挤压、强烈海报化表达。
- 只学习：黑橙双色、身体景观化、版画颗粒、大片留白。
- 不复制：巨手、巨腿、军阵或峡谷位置。

## 07 — Void and Witnesses

Path: `references/images/07-void-and-witnesses.jpg`

- 核心：暖白虚空占据绝大面积，边缘人群向下溶解，底部只保留一个克制仪式。
- 适用：死亡、记忆、告别、审讯、见证、孤独、历史回声。
- 只学习：大面积空白、低位焦点、群体边界和单一暗红强调。
- 不复制：亡魂、献祭、跪地战士。

## 08 — Voice as Space

Path: `references/images/08-voice-as-space.jpg`

- 核心：两张侧脸隐藏在负形中，声音或气流成为覆盖天空的线束，微小主体位于下方。
- 适用：歌声、对话、诱惑、记忆、舆论、无形影响、两人关系。
- 只学习：负形人脸、流线交织、对称框架中的微小不稳定点。
- 不复制：长船、桅杆、被绑人物或塞壬情节。

## 09 — Transformation Spiral

Path: `references/images/09-transformation-spiral.jpg`

- 核心：一个连续路径同时表现时间与变形，控制者位于画面边缘，未被改变者站在循环之外。
- 适用：成长、腐化、身份变化、重复、诱惑、习惯、选择。
- 只学习：螺旋叙事、阶段性变形、局部暗红轴线和边缘巨型人物。
- 不复制：长发、酒液、士兵变野猪或古代服装。
